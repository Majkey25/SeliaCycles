# Calendar widget verification

The home-screen widget uses native Android RemoteViews and the app's calendar calculations. It is bound to one local profile. Cycle markings require an explicit choice during setup. It does not access the external calendar provider.

## Checks completed on October 7

- 189 JVM tests passed.
- Full isolated Android QA suite: 61 tests passed on the Huawei YAL-L21, Android 10.
- Widget tests cover provider registration, native AppWidgetHost binding, setup, month navigation, Today, opening the bound profile and refresh after saving a local record.
- Native rendering checked in light/dark mode, with app-specific Czech labels on an English host.
- Deleted-profile and recovery tests reapply views to the same host root. Stale profile names and cycle markings are cleared.
- Appearance tests cover background opacity, custom colors, reload, reset and Cancel preserving saved choices.
- Color-picker selection and transparency slider were exercised through the real setup UI.
- Release build passed. Lint reported zero errors and nine existing warnings.

The appearance regression failed before implementation with expected image alpha 64 versus actual 255. It passed after the widget applied the saved opacity. Earlier device tests exposed an Android 10 RemoteViews alpha incompatibility, which was removed before final verification.

Only the isolated QA package and synthetic profiles were used. Both QA packages and the temporary test widget host were removed. Production app data and Google Calendar were untouched. Tests cover the native widget host, not every launcher's layout or wallpaper. Readability with transparency depends on the chosen wallpaper.
